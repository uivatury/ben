  Current Options:

  1. Default (no flags): Human-readable output (basic)
  2. --verbose: Human-readable output with extra details (confidence analysis, entropy, timing)
  3. --json: JSON output only (no human text)
  4. --json --verbose: JSON output with extra data (all 40 bid probabilities)

  So --verbose is NOT the default - it adds extra information to whichever output format you're using.

  Examples:

  # Default - Basic human output

  Key Pattern Changes:

  - Model auto-selection: lefty → dummy → righty → decl → righty (for trick 2 leader)
